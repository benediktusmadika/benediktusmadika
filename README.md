## 🧪 Research Experience  

### 🔋 ML-Driven Primary Particle Size Prediction (KAIST)  
**Role:** ML Research Engineer  
**Period:** Oct 2024 – Sep 2025  

- Developed probabilistic ML framework (NGBoost) under incomplete data  
- Integrated MatImpute for chemistry-aware imputation  
- Achieved **R² = 0.866**, **AUCE = 0.133**  
- Identified key synthesis factors via SHAP  
- Experimentally validated on NCM811 samples  

**Methods:** NGBoost • Uncertainty Quantification • SHAP • Data Imputation
